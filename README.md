# Messenger

Мобильный веб-мессенджер на Node.js, Express и Socket.IO. База данных не нужна: пользователи, сообщения и новости хранятся в JSON-файлах на сервере, а загруженные картинки и файлы складываются в `public/uploads`.

## Возможности

- вход только по логину и паролю;
- уникальный тег пользователя, который сохраняется в `localStorage` после входа;
- поиск людей по тегу;
- профиль с аватаркой, именем, тегом и ролью;
- личные сообщения в реальном времени;
- отправка текста, картинок и файлов;
- лента новостей с картинкой и текстом;
- лайки и комментарии к новостям;
- создание, редактирование и удаление новостей только админами;
- интерфейс, рассчитанный на телефон.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Стартовые аккаунты

Если `data/users.json` ещё не существует, сервер создаст пользователей:

- админ: `admin` / `admin123`, тег `@admin`;
- пользователь: `demo` / `1234`, тег `@demo`.

## Серверные данные

При первом запуске создаются файлы:

- `data/users.json`;
- `data/messages.json`;
- `data/news.json`;
- `public/uploads/` для вложений и картинок.

Эти файлы добавлены в `.gitignore`, потому что это рабочие данные сервера.

## API

- `POST /login` - вход;
- `GET /me` - текущий профиль;
- `GET /users/:id` - список пользователей;
- `GET /search-users?tag=...` - поиск по тегу;
- `GET /profile/:id` - профиль пользователя;
- `PUT /profile/:id` - обновление имени/аватарки;
- `GET /messages/:me/:him` - история диалога;
- `POST /upload` - загрузка вложения для сообщения;
- `GET /news` - лента;
- `POST /news` - создать новость, только админ;
- `PUT /news/:id` - изменить новость, только админ;
- `DELETE /news/:id` - удалить новость, только админ;
- `POST /news/:id/like` - лайк;
- `POST /news/:id/comments` - комментарий.
